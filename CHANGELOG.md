# Changelog

## 0.2.0 - 2026-07-05

- Redesigned GUI around visual Android folder selection.
- Added Pixel 5 folder browser.
- Removed technical route/path selection from normal UI.
- Added CLI `--folder`, `--list-folders`, and `--create-folder`.
- Updated SendTo behavior so files open queued instead of sending immediately by default.
- Fixed empty mkdir destination bug.
- Improved icon, visuals, and GitHub release package.
- Added tests for folder mapping and mkdir regression.

## 0.1.0 - 2026-07-05

- Initial public-ready project structure.
- Added Python/Tkinter Windows utility fallback.
- Added ADB discovery, WSA connection, file routing, push, verification, media-scan request, CLI, GUI, SendTo installer, optional context-menu installer, diagnostics, tests, docs, and release packaging scripts.
