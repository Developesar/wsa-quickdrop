# راه‌اندازی WSA

## فعال کردن Developer Mode

1. تنظیمات Windows Subsystem for Android را باز کنید.
2. Developer Mode را فعال کنید.
3. یک برنامه اندرویدی را اجرا کنید تا WSA روشن شود.
4. پورت ADB را بررسی کنید. مقدار پیش‌فرض معمولا `127.0.0.1:58526` است.

## تست اتصال

```powershell
adb connect 127.0.0.1:58526
adb devices
```

باید دستگاهی شبیه این ببینید:

```text
127.0.0.1:58526    device
```

## اگر connection refused دیدید

- مطمئن شوید WSA اجرا شده است.
- یک برنامه اندرویدی را یک بار باز کنید.
- Developer Mode را دوباره بررسی کنید.
- پورت نمایش‌داده‌شده در تنظیمات WSA را چک کنید.
- WSA را restart کنید و دوباره تلاش کنید.
